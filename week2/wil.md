## git clone
- git clone으로 레포지토리 다시 복사해서 쓸 수 있음
### 관련 명령어
- ls - 폴더 안에 어떤 파일, 폴더가 있는지 알 수 있음
- pwd - 지금 위치를 보여줌
- cd <폴더 이름> 치면 거기로 들어가게 됨
- cd ..을 하면 그 폴더를 나갈 수 있음

## html 조금 더 알아보기 - 
- 문서 양식을 통합하기 위해 만듬
- markuplanguage - 텍스트 외의 부가적인 의미를 부여하는 방법
### html의 의미
- hyper의 뜻: 넘어서, 초월
- hypertext: 텍스트를 넘어서, 텍스트를 초월한
- hypertext를 통해 더이상 쪽번호가 필요없어짐, index 목차가 필요함
- hyperlink 느낌인거 같음

## python.html만들기
- 링크 연결을 할거임
- 기존 url/python.html이런식
### 두 페이지 연결하기
``` html
<a href = "./python.html"> 파이썬 </a>
```
- 목차만 있으면 목차에서 다른 페이지로 넘어갈 수 있게 됨
- 목차가 중심이고 중요함
- index.html은 생략되서 뒤에 적을 필요 없음
- 어차피 쳐도 똑같이 들어감
``` html
<!DOCTYPE html>
```
- 문서 타입(document type)

## 색깔 넣기
